# Path of Upgrading

An item overlay for Path of Exile 2 on Linux. Copy an item in game and it tells
you whether that item is an upgrade for your character, using Path of Building
to do the maths, and it can search the trade site for better gear.

Path of Upgrading is being rebuilt as a native Qt application. KDE Plasma on
Wayland is the first supported desktop; other desktops and Windows come later.
